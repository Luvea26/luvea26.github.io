# LUVEA Website — Free Static Version

This package is a complete responsive starter website for LUVEA.

Pages:
- Home
- Collections
- Product
- About
- Contact
- Cart drawer with WhatsApp ordering

Important:
- LUVEA is currently online-only; there is no physical shop location in the site.
- Product photos/prices are starter content based on the approved visual direction. Replace them with the real product photos/prices before publishing.
- WhatsApp ordering is wired to 010 1933 6292.
- Instagram is linked to @luvea.26.

How to publish for free:
1. Upload the contents of this folder to a static hosting service or a GitHub repository.
2. Enable the host's static-site publishing.
3. Your site will be live on its free URL.
4. Later, a custom domain can be connected.

For Google Sites specifically, this package is better treated as the design/source reference because Google Sites uses its own page editor rather than importing a complete HTML site.
